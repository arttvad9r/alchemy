# Алхимия: полировка анимаций и подачи

**Цель:** довести ощущение игры: анимации рабочей области, эффекты открытия по редкости, плашка достижений, плавные переходы, единый стиль экранов.

**Ограничения:**
- Механику не менять (состав каталога, рецепты, редкость, правило перекрытия). Только стиль и подача.
- Рабочую область не сохранять между запусками (решение пользователя).
- Новые звуки не генерировать; для достижения использовать существующий.
- Ветка `feat/polish` от `master`, один коммит на этап, без push.
- Проверка: `./gradlew qualityCheck testDebugUnitTest assembleDebug`, целевые инструментальные тесты, эмулятор `claude-alchemy-qa` (`ANDROID_SERIAL=emulator-5580`), `font_scale 1.3`. Звук и вибрацию на эмуляторе проверить нельзя, это делает пользователь на телефоне.

## Этап 1. Ощущение рабочей области
Файлы: `WorkspaceCanvas.kt`, `HomeScreen.kt`, `WorkspaceTransitions.kt`, `AlchemyViewModel.kt`.
- [ ] Удерживаемый элемент рисуется последним; приподнимание (scale ≈1.12, тень), возврат пружиной.
- [ ] Подсветка цели при перетаскивании; правило перекрытия вынести из редьюсера в общую функцию. Подсвечивать любую пару, чтобы не подсказывать рецепты. Эллиптический радиус перекрытия не менять без решения пользователя.
- [ ] Появление элемента: масштаб 0.6→1 (spring), искры остаются.
- [ ] Слияние: `CombinationEffect` несёт два исходных элемента с позициями; они стягиваются к точке слияния (~200 мс), результат вылетает на пике вспышки.
- [ ] Неверная пара: новый вид перехода `SHAKE`, покачивание перетащенного элемента.
- [ ] Пустая плита: показать `workspace_hint` тихим текстом; пропадает с первым элементом.
- [ ] Палитра: тащимая плитка притухает; при тапе элемент вылетает из палитры в позицию появления.
- [ ] Unit-тесты: `itemTransitions` (SHAKE, слияние), общая функция перекрытия.
