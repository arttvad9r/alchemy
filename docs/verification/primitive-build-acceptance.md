# Выпускная проверка primitive-сборки

Дата проверки: 27 сентября 2026 года  
Пакет: `com.artt.alchemy`

## Проверенный gate

Успешно выполнено:

```bash
./gradlew formatCode testDebugUnitTest qualityCheck assembleDebug assembleRelease lintDebug assembleDebugAndroidTest
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5554 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5554 shell pm clear com.artt.alchemy
adb -s emulator-5554 shell am instrument -w com.artt.alchemy.test/androidx.test.runner.AndroidJUnitRunner
```

Результаты:

- 17 unit-тестов: `0` failures, `0` errors;
- 13 Compose instrumentation-тестов: `OK`;
- `qualityCheck`, debug/release APK и lint завершились успешно;
- Android Lint: 21 информационное предупреждение, 0 ошибок. Предупреждения относятся к намеренно фиксированной портретной ориентации, доступным обновлениям версий и ранее существующей конфигурации; они не блокируют сборку.

## Проверенные сценарии

- Палитра добавляет элемент только долгим перетаскиванием; касание и обычная прокрутка не создают копию.
- Захват экземпляра на поле берёт точку первого касания, поэтому быстрый drag не теряет объект после touch slop.
- Перетаскивание палитры прямо на элемент поля сразу проверяет рецепт: `Огонь + Вода → Пар`; два исходных экземпляра не остаются наложенными.
- Учитывается только реальная попытка наложения. Обычное размещение и близкие, но не пересекающиеся элементы не увеличивают «Эксперименты».
- Успешное сочетание даёт звук/вибрацию согласно сохранённым настройкам и показывает диалог «Новый элемент» при первом открытии результата.
- В Элементах доступны подписанный поиск и фильтр групп; в Рецептах — фильтр по элементу; достижения включают общий и групповой прогресс с состоянием «Получено».
- Палитра использует пять колонок, показывает подсказку drag и не создаёт лишнего пустого блока; базовые Огонь, Вода, Земля и Воздух различаются цветом.
- Визуально на `emulator-5554` проверены читаемая подсказка, одна компактная строка первых пяти открытых элементов, отсутствие обрезаний и перекрытий на главном экране.

Готовые PNG-ассеты пока намеренно не подключены: этап primitive-first закончен, а переход к предоставленному набору ассетов остаётся отдельной художественной задачей.
