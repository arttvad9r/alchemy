# Алхимия

Оффлайн Android-игра о комбинировании элементов. Проект написан на Kotlin и Jetpack Compose, рассчитан на портретную ориентацию и Android 12+ (API 31).

## Запуск

1. Откройте проект в Android Studio или используйте Gradle Wrapper.
2. Подключите Android-устройство либо запустите эмулятор.
3. Выполните:

```bash
./gradlew installDebug
adb shell am start -n com.artt.alchemy/.MainActivity
```

Пакет приложения: `com.artt.alchemy`.

## Проверка

```bash
./gradlew qualityCheck
```

Полный набор команд находится в [docs/testing.md](docs/testing.md).

## Граница текущего этапа

Сейчас реализуется **primitive-first** версия: только Compose-примитивы, Canvas, текст и простые панели. PNG из предоставленного набора ассетов намеренно не добавляются до явного подтверждения механик пользователем.

Игра не использует сеть, аккаунты, рекламу, покупки, аналитику или сторонний игровой движок.
