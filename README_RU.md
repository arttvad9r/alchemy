# Алхимия

Оффлайн Android-игра о комбинировании элементов. Проект написан на Kotlin и Jetpack Compose, рассчитан на портретную ориентацию и Android 12+ (API 31).

## Запуск

1. Откройте проект в Android Studio или используйте Gradle Wrapper.
2. Подключите Android-устройство либо запустите эмулятор.
3. Выполните:

```bash
./gradlew installDebug
adb shell am start -n com.artt.alchemy/.MainActivity
```

Пакет приложения: `com.artt.alchemy`.

## Проверка

```bash
./gradlew qualityCheck
```

Полный набор команд находится в [docs/testing.md](docs/testing.md).

## Граница текущего этапа

Механики primitive-first версии подтверждены, идёт поэтапное подключение готовых ассетов. Подключены иконки элементов (`tools/build_element_icons.py`) и оболочка интерфейса: тёмная тема, фон Aether, иконки навигации и настроек, рамки редкости (`tools/build_ui_assets.py`). Редкость элемента вычисляется по глубине дерева рецептов. На рабочем поле стоит алтарь с магическим кругом; удачное смешивание сопровождается вспышкой, новое открытие — золотыми искрами, после которых появляется карточка элемента. Кнопки, переключатели, вкладки, поля и диалоги нарисованы ассетами (растягиваются по 9-slice, см. `AlchemyControls.kt`).

Игра не использует сеть, аккаунты, рекламу, покупки, аналитику или сторонний игровой движок.
