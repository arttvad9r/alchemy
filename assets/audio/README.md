# Звуки и музыка

`tools/build_audio.py` (нужен ffmpeg) кладёт эти файлы в `app/src/main/res/raw`.

## Эффекты и музыка — Stable Audio 3

Сгенерированы локально моделью Stable Audio 3 `medium` (и `small-sfx` для части первого набора) от Stability AI. На каждый звук — несколько идей и много дублей; лучшие отобраны автоматически (сходство с описанием по CLAP, штрафы за шум, двойной удар и обрезанный хвост), окончательный вариант выбран на слух. Файлы уже обрезаны до одного события, очищены от гула и резкого верха, выровнены по общей лестнице громкости (клик тише всего, большое открытие громче всего, пик не выше −1 dBFS), а музыка склеена в петлю, поэтому скрипт копирует их без перекодирования. Все эффекты моно, чтобы игра могла сдвигать их туда, где на поле произошло событие. Модели распространяются под [Stability AI Community License](https://stability.ai/community-license-agreement): права на результат генерации остаются у автора, коммерческое использование разрешено.

| Файл | Где звучит |
| --- | --- |
| `stable-audio/place.ogg` | элемент поставлен на поле — камешек на дереве |
| `stable-audio/pickup.ogg` | элемент взят в руку — на поле или из палитры, пробка |
| `stable-audio/discover.ogg` | открыт новый элемент |
| `stable-audio/discover_grand.ogg` | открыт эпический или легендарный элемент — хор и колокола |
| `stable-audio/no_match.ogg` | пара не сочетается — глухой деревянный стук |
| `stable-audio/remove.ogg` | элемент убран за край поля — лопнувший пузырь |
| `stable-audio/whoosh.ogg` | кнопка «Очистить» — магический взмах |
| `stable-audio/click.ogg` | вкладки и кнопки |
| `stable-audio/page.ogg` | переход на экран рецептов — страница старой книги |
| `stable-audio/hint.ogg` | подсказка на экране «Рецепты» — калимба |
| `stable-audio/achievement.ogg` | получено достижение — фанфара |
| `stable-audio/music.ogg` | фоновая музыка, по кругу |

Сброс прогресса и переключатели в настройках звука не издают — только вибрацию, где она была.

## Как звуки смешиваются в игре

- Частые эффекты (поставить, убрать, смешать, клик) каждый раз чуть меняют высоту, чтобы повторы не звучали одинаково.
- Звуки на поле слышны с той стороны, где было событие.
- Удачные смешивания подряд, без пауз и промахов, звучат с каждым разом на полтона выше.
- Под открытием и достижением музыка ненадолго становится тише и потом плавно возвращается.
