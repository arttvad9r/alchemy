# Звуки и музыка

`tools/build_audio.py` (нужен ffmpeg) кладёт эти файлы в `app/src/main/res/raw`.

## Эффекты и музыка — Stable Audio 3

Сгенерированы локально моделями Stable Audio 3 (`medium` и `small-sfx`) от Stability AI и выбраны на слух из нескольких вариантов. Файлы уже обрезаны, выровнены по громкости, а музыка склеена в петлю, поэтому скрипт копирует их без перекодирования. Модели распространяются под [Stability AI Community License](https://stability.ai/community-license-agreement): права на результат генерации остаются у автора, коммерческое использование разрешено.

| Файл | Где звучит |
| --- | --- |
| `stable-audio/place.ogg` | элемент поставлен на поле |
| `stable-audio/discover.ogg` | открыт новый элемент |
| `stable-audio/no_match.ogg` | пара не сочетается |
| `stable-audio/remove.ogg` | элемент убран за край поля |
| `stable-audio/click.ogg` | вкладки и кнопки |
| `stable-audio/page.ogg` | переход на экран рецептов |
| `stable-audio/music.ogg` | фоновая музыка, по кругу |

Сброс прогресса и переключатели в настройках звука не издают — только вибрацию, где она была.

## Синтезированные эффекты — `procedural/`

Собраны кодом, без сэмплов и нейросетей: `tools/build_procedural_audio.py` (нужны numpy, scipy и soundfile, только для разработки) синтезирует их из колокольчиков, отфильтрованного шума и простого ревербератора. Колокольчики настроены на ре-минорную пентатонику — в тональности фоновой музыки, поэтому не спорят с ней. Все эффекты моно, чтобы игра могла сдвигать их влево или вправо — туда, где на поле произошло событие. Результат детерминирован: скрипт каждый раз даёт те же файлы. Лицензия — как у кода, MIT.

| Файл | Где звучит |
| --- | --- |
| `procedural/pickup.ogg` | элемент взят в руку — на поле или из палитры |
| `procedural/whoosh.ogg` | кнопка «Очистить» |
| `procedural/hint.ogg` | подсказка на экране «Рецепты» |
| `procedural/achievement.ogg` | получено достижение |
| `procedural/discover_grand.ogg` | открыт эпический или легендарный элемент |

## Как звуки смешиваются в игре

- Частые эффекты (поставить, убрать, смешать, клик) каждый раз чуть меняют высоту, чтобы повторы не звучали одинаково.
- Звуки на поле слышны с той стороны, где было событие.
- Удачные смешивания подряд, без пауз и промахов, звучат с каждым разом на полтона выше.
- Под открытием и достижением музыка ненадолго становится тише и потом плавно возвращается.
