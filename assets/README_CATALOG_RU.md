# Alchemy Forge — Clean Assets v2

Эта версия пересобрана после проверки прошлой нарезки. Вместо прямоугольной нарезки используется сегментация по прозрачности и принадлежность каждого полупрозрачного пикселя ближайшему объекту. Это убирает куски соседних иконок и при этом сохраняет собственное свечение.

В `previews/` есть контактные листы для визуальной проверки всех групп.
